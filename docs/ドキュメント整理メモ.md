# ドキュメント整理メモ

更新日: 2026-05-09

## 目的

このメモは、現在のドキュメントを「現役」「参照用」「アーカイブ候補」「要確認」に分け、今後の実装判断で迷わないようにするための棚卸しです。

まだファイル削除はしない。まずは索引を作り、古い前提の文書を現役仕様として読まないようにする。

## 現在の大きな流れ

現行システムは、初期の「AIノベルゲーム制作ツール」から、以下を組み合わせたラプラスシティ型の創作/会話/生活シミュレーションへ広がっている。

- プロジェクト、キャラクター、世界観、アセット管理
- ライブチャット、ルーム、親密度、記憶、目的メモ
- おでかけ、ギフト、クローゼット、メール、Feed、ワールドニュース
- ストーリー/TRPG風セッション
- シネマノベル、章生成、画像生成、エクスポート
- 公開運用、ユーザー権限、管理機能

そのため、初期MVP設計や旧シーン編集中心の設計は、現行仕様ではなく「参照用」または「アーカイブ候補」として扱う。
