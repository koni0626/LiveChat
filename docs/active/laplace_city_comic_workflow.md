# ラプラスシティ漫画制作ワークフロー

更新日: 2026-05-16

## 位置づけ

ラプラスシティは、もともとチャットサービス用に育った世界観・キャラクター群だが、今後は漫画・シネマノベル・短編作品として展開できるIPとして扱う。

制作では、アプリDBを直接の作業場にしすぎず、次の役割分担を採用する。

- `instance/app.db`: 原典データベース。キャラクター、世界観、施設、Feed、ニュース、会話ログ、画像アセットを保持する。
- `creative/laplace_city/`: 漫画制作の編集室。作品ごとの脚本、ネーム、ページプロンプト、出力物、設定スナップショットを置く。

DBは「生きたキャラの記憶」、制作フォルダは「売る作品の設計図」として分ける。

## 基本方針

- 漫画制作は `creative/laplace_city/` 配下で進める。
- DBから抜き出した情報は、作品単位または制作バイブル単位でMarkdownに固定する。
- 作品化する内容は、チャット用設定をそのまま使うのではなく、読者に伝わる形へ編集する。
- 画像生成では、キャラクターの参照画像を必ず確認し、髪型、衣装、色、役割が混ざらないようにする。
- DBを直接参照して作業してもよいが、最終的な脚本・ページ構成・プロンプトは制作フォルダに残す。

## 推奨フォルダ

```text
creative/laplace_city/
  README.md
  bible/
    world.md
    characters.md
    locations.md
    visual_references.md
  stories/
    <story_slug>/
      premise.md
      outline.md
      script.md
      storyboard.md
      page_prompts.md
      notes.md
  comics/
    <story_slug>/
      page_001/
      page_002/
  exports/
```

## DBから抽出する主な素材

- `world`: ラプラスシティの時代、技術、社会構造、ルール、禁止事項。
- `character`: キャラクター名、概要、性格、口調、一人称、二人称、NG、外見。
- `asset`: キャラクター基準画像、ブロマイド、サムネイル。
- `world_location`: 施設、地区、デートコース、背景候補。
- `world_news_item`: 都市内事件、噂、ニュース化できるネタ。
- `feed_post`: キャラの投稿、口調、関係性、日常ネタ。
- `cinema_novel*`: 既存の作品、ロア、レビュー、印象。

## 漫画制作手順

1. 作品フォルダを作る。
2. DBから必要キャラと世界観だけを抜き出し、設定スナップショットを作る。
3. 読者向けの前提説明を整理する。
4. 短いプロットを作る。
5. ページ単位でコマ割りとセリフを作る。
6. 画像生成前に、ページごとのキャラ配置と参照画像を確認する。
7. 画像を生成する。
8. セリフ、コマ割り、キャラ識別、読みやすさを確認し、必要ならページ単位で再生成する。
9. 採用プロンプトと出力物を制作フォルダに残す。

## 画像生成ルール

- キャラクター集合絵では、全員の参照画像を会話または作業文脈で確認してから生成する。
- ラプラス、ノア、ドル、ウォズ、リーク、レイジアなど、髪色や衣装の近いキャラは配置と特徴を明示する。
- 画像内の日本語テキストは崩れる可能性があるため、重要なセリフは別途 `script.md` または `storyboard.md` に保持する。
- 漫画ページでは、まず「文字少なめのラフ漫画」として生成し、必要に応じて後から文字入れや再生成を行う。
- 販売用にする場合は、最終画像を `creative/laplace_city/exports/` または作品別フォルダにコピーし、採用版を明確にする。

## 現在の試作

題材: `ラプラス、波動関数に敗北す`

中心アイデア:

- ラプラスはラプラスの悪魔をベースにした統治AI。
- シュレディンガー方程式の「確率で答える」考え方が大嫌い。
- ウォズが、量子力学を知らない読者にも分かるように「天気予報みたいに確率で答える」と説明する。
- ラプラスは「自然、提出期限を守りなさい！」とキレる。
- その後、箱入りプリン実験、プリン消失、レイジアの「保護しました」オチへ進む。

重要セリフ:

- ウォズ: 「小さい世界の“次”を計算する式だよ」
- ウォズ: 「でも答えは『絶対こう』じゃない」
- ウォズ: 「雨の確率70％みたいに、確率で答える」
- ラプラス: 「宇宙が天気予報みたいな返事を？」
- ウォズ: 「雑に言えばね」
- ラプラス: 「わたくしはラプラスの悪魔を継ぐ者ですのよ？」
- ウォズ: 「だから相性が悪い」
- ウォズ: 「この式は“まだ一つに決めない世界”を扱う道具だから」
- ラプラス: 「自然、提出期限を守りなさい！」
