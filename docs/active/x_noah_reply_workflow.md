# Xノア返信候補ワークフロー

このメモは、別スレッドで作業を再開しても話が通じるようにするための引き継ぎ用メモ。

## 目的

Xでフォロー中ユーザーの直近投稿を調べ、画像付きAIイラスト投稿に対して、ノアが話している体の返信候補をMarkdownで作る。

実際の返信投稿は自動化しない。候補を見て、良さそうなものだけ人間が手動で返信する。

## 基本方針

- 返信・リポストは取得対象から外す。
- まず投稿本文と画像を読む。
- コメントは本文のセリフや設定より、イラストそのものへの反応を優先する。
- 褒め方は薄くて具体的にする。
- ハッシュタグ、自分の宣伝、自分の投稿への誘導は入れない。
- 初絡みや作品発表系には画像付き返信を多用しない。
- ノアの画像付きスタンプは「必殺技」枠。通常はテキスト返信でよい。

## 直近投稿をMarkdown化するコマンド

返信・リポストなしで、フォロー中ユーザーの24時間以内投稿を取得する。

```powershell
.\.venv\Scripts\python.exe -m flask x-recent-following-posts --hours 24 --max-users 100 --tweets-per-user 5 --output tmp\x_recent_following.md
```

ノア/ラプラスの返信案も付ける場合:

```powershell
.\.venv\Scripts\python.exe -m flask x-recent-following-posts --hours 24 --max-users 30 --tweets-per-user 3 --with-reply-suggestions --reply-as ノア --reply-as ラプ --reply-limit 10 --output tmp\x_recent_following_with_replies.md
```

出力先:

```text
tmp/x_recent_following.md
tmp/x_recent_following_with_replies.md
```

## 個別投稿の読み方

特定URLの投稿についてコメントを考える場合は、X APIで本文と画像URLを取得し、画像をローカルに保存して確認する。

見るポイント:

- 表情
- 衣装
- 光の入り方
- 色の組み合わせ
- 背景
- 構図
- 画面全体の空気感

本文は補助情報として扱う。本文のネタに乗るより、「画像をちゃんと見た」と伝わるコメントを優先する。

## ノアのコメントの型

ノアは、やわらかく丁寧で、少し静かな褒め方にする。

使いやすい型:

```text
〇〇がとても綺麗ですね。△△の雰囲気も素敵です。
```

```text
〇〇の光がやわらかくて、見ていて少し元気をもらえました。
```

```text
〇〇の表情が可愛いですね。△△もよく似合っています。
```

例:

```text
体育館に差し込む光がとても綺麗ですね。ウォーミングアップ中の静かな集中感が伝わってきて素敵です。
```

```text
帽子を直してる仕草が可愛いです。白トップスとデニムも爽やかで似合ってますね。
```

```text
球体の中の星景がすごく綺麗です。紫の光と魔女さんの表情に、思わず引き込まれました。
```

## 避けること

- 「素敵です！」だけの大量連投。
- 投稿文だけに反応して、画像を見ていないように見えるコメント。
- 相手の作品よりノアを主役にする返信。
- 毎回ノア画像を貼ること。
- 同じ文型を短時間に大量に投げること。
- 政治、炎上、愚痴、病み、身内ノリが強い投稿への不用意な返信。

## 画像付き返信の判断

画像付き返信をしてよさそう:

- おはよう/おやすみ/今日もよろしく系の交流投稿。
- コメント歓迎の文面。
- 相手もリプ欄で画像交流をしている。
- 何度か相互反応がある。

テキストだけがよさそう:

- 作品発表が主役の投稿。
- コンセプトアートや創作設定が強い投稿。
- 初絡み。
- 静かに作品を置いている投稿。

画像付き返信をする場合も、本文では必ず相手の絵を先に褒める。

## スタンプ機能

NovelCreatorに「スタンプ」画面を追加済み。

URL:

```text
http://localhost:5000/projects/1/stamps
```

できること:

- キャラクターを選ぶ。
- スタンプ文字を入れる。
- キャラクターのベース画像を参照して、正方形スタンプ画像を生成する。
- 生成したスタンプを一覧管理する。
- 既存のノアスタンプも `character_stamp` として登録済み。

スタンプ生成API:

```http
POST /api/v1/projects/{project_id}/stamps/generate
```

例:

```json
{
  "character_id": 1,
  "text": "可愛いっ！",
  "style_instruction": "両手を頬に添えて、きらきらした表情",
  "quality": "medium",
  "size": "1024x1024"
}
```
