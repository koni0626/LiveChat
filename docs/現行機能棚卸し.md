以下のBlueprintディレクトリは残っているが、現時点では `routes.py` がなく、`create_app` にも登録されていない。

- `chapters`
- `ending_conditions`
- `exports`
- `glossary`
- `jobs`
- `scene_images`
- `scene_versions`
- `scenes`
- `story_outline`

扱い案:

- 旧MVP制作フローの名残として保守対象/アーカイブ対象に分類する
- 実装復活する場合は、現行の `stories` / `cinema_novels` / `live_chat` と重複しない用途を定義する
