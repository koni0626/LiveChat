# Roadmap

更新日: 2026-05-09

## 方針

現行システムは、ラプラスシティ内でキャラクターが会話し、記憶し、行動し、世界ニュースやFeedに痕跡を残す体験を中心に育てる。

初期のシーン/チャプター/ストーリー骨子中心フローは保守対象として残しつつ、新規強化は以下を優先する。

1. ライブチャット、記憶、親密度
2. Feed、World News、おでかけ、メールの循環
3. ストーリー/TRPG風セッション
4. シネマノベル制作/閲覧
5. 公開運用、権限、安定性

## 優先度 A

### 1日1ターン生活ループ

プレイヤーが1日に数回だけ行動を選び、結果が短いイベント、画像、記憶、ニュース、Feedに反映されるループを作る。

候補アクション:

- 誰に会う
- どこへ行く
- 何を贈る
- 何を投稿する
- どの噂を調べる
- 店や施設を訪れる

最初の実装案:

- 既存のおでかけ、Feed、World News、記憶を接続する
- まずは1プロジェクト単位の「今日の行動」API/UIを作る
- 数値スコアは控えめにし、文章と痕跡を主役にする

### キャラ自律行動ログ

ユーザーが操作していなくても、キャラクターが世界内で少し動いたように見せる。

例:

- 観測塔で変なログを見つけた
- 店に新商品を出した
- 深夜配信をした
- ほかのキャラに会った

出力先:

- Feed
- World News
- ライブチャットの話題
- キャラクター記憶

現状:

- [キャラクター自律行動ログ](./active/autonomous_character_actions.md) として、Flask CLIコマンド版を追加。
- まずは Feed / World News / both を選んで生成できる。
- スケジューラ化、記憶/会話への注入は次段階。

### 記憶の構造化

現状の記憶を、後から編集/参照しやすいカテゴリへ寄せる。

候補カテゴリ:

- 好きなもの
- 苦手なもの
- 趣味
- 境界線/NG
- 印象的な出来事
- プレイヤーへの呼び方
- 関係性の根拠
- 贈り物の好み

残件:

- `memory_profile_json` 相当の構造化
- 記憶閲覧/編集UI
- AI構造化出力での更新
- テスト整備

## 優先度 B

### おでかけ結果の循環

おでかけ完了結果を、ほかの機能へ自然に流す。

接続先:

- メール
- Feed
- ライブチャットの話題
- キャラクター記憶
- World News

既存残件:

- 完了時の画像を「思い出CG」として採用/再生成
- 施設ごとのイベントテンプレート管理

### 画像ギフト

ユーザーが画像をアップロードして、キャラクターに贈れるようにする。

最小案:

- 画像アップロード
- AIで品物判定
- 好み/苦手/境界線との照合
- 反応セリフと記憶更新
- 受け取った品のサムネイル表示

### Conversation Director 強化

発話生成の前に、ターンの意図を明示的に決める。

候補:

- `invite`
- `tease`
- `reveal`
- `test`
- `comfort`
- `escalate`
- `retreat`

狙い:

- 同じような返答の連続を減らす
- キャラが意志を持って会話している感覚を強める
- 画像生成や目的メモとも方向性を揃える

## 優先度 C

### 正式採用機能の仕様整理

試作的に追加した機能は、すべて正式採用とする。

まず仕様整理するもの:

- ライブチャット派生機能
- 所持品/ギフト/親密度報酬
- スタジオ
- ポイント

正式化済み:

- [シネマノベル正式仕様](./active/cinema_novels.md)

正式採用した機能の詳細は [正式採用機能まとめ](./実験的機能まとめ.md) を参照する。

### ストーリー/TRPGとメールの接続

ストーリーセッション内の重要イベントをメール候補として記録し、後日の手紙やFeedに反映する。

候補イベント:

- 手を取った
- かばった
- アイテムを渡した
- 危険を一緒に越えた
- 約束をした

### シネマノベル制作フローの運用整備

シネマノベル/ショートコミックは正式機能。管理者とプロジェクトユーザーにとっては制作機能かつ閲覧機能、一般ユーザーにとっては閲覧機能のみとする。

整備する内容:

- UI上で一般ユーザーに制作操作を出さない
- API側でも制作操作をプロジェクト管理権限に限定する
- READMEに概要を追加する
- 通常シネマノベルとショートコミックの違いをUI文言で明確にする
- EPUB/PowerPoint/short video/comic short video出力の失敗時メッセージと保存先を整理する

### API/テスト/運用整備

残件:

- 主要API Happy Pathテスト
- OpenAI API実接続確認
- APIキー未設定時のエラー表示
- migration適用状況の確認
- READMEへの主要機能一覧追加
