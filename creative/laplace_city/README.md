# ラプラスシティ漫画制作室

このフォルダは、ラプラスシティを漫画・短編作品として制作するための作業場所です。

詳しい運用方針は `docs/active/laplace_city_comic_workflow.md` を参照してください。

## 役割

- DBは原典です。
- このフォルダは編集室です。
- 作品化する設定、脚本、ネーム、画像プロンプト、採用画像をここに残します。

## フォルダ

- `bible/`: 世界観、キャラクター、施設、参照画像の制作バイブル。
- `stories/`: 作品ごとの企画、脚本、コマ割り、セリフ。
- `comics/`: ページ単位の生成物、ページプロンプト、採用候補。
- `exports/`: 販売・共有用の最終出力。

## 現在の試作

- `ラプラス、波動関数に敗北す`
  - ラプラスがシュレディンガー方程式にキレるSFコメディ。
  - 読者向けに、ウォズが「確率で答える式」として分かりやすく説明する。
  - その後、箱入りプリン実験とプリン消失事件へつなげる。
