# 旧人類、OSで戦争す

## ステータス

本編化済み。

## 位置づけ

第17話。

第16話「きのこの山、たけのこの里戦争」に続く、旧人類のしょうもない派閥対立シリーズ。

火星移住後も「WindowsかMacか」の論争を捨てられず、OS選定が標準化、互換性、保守性、デザイン、自己像の問題に発展する。

## コアアイデア

旧人類は、道具の違いを思想にする。

端末はただの道具だった。

しかし、どちらを使うかは、仕事観、美意識、所属意識、自分がどういう人間でありたいかに結びついた。

そのため火星でも、OS選定は宗教戦争のようにこじれた。

## 注意

- 実在OS名を使うため、片方を貶めない。
- Windows派にもMac派にも一理ある形にする。
- 笑う対象は、旧人類が道具に自尊心と信仰を接続してしまうところ。
