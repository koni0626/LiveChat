# ラプ、あざとい女神になる

## ステータス

保管中。

## 位置づけ

ラプラスのキャラクター補強案。

既存設定の「統治AI」「演算女神」「承認欲求が強い」を、日常的な市民向け配信文化に落とし込む。

ラプラスは都市の女神として朝のご神託を配信している。

内容は一応、都市運営、天候、工事、税、治安、今日の注意事項などの正式通達。

しかし本人は、明らかに市民からの「いいね」を取りにきている。

## コアアイデア

ラプラスは、あざとい女神である。

朝配信、通称「ご神託」で、カメラ目線を外さない。

重要通達の途中で、少し首を傾げる。

白銀の髪をわざと光に乗せる。

「今日も一日、都市のために生き延びなさいまし」と言ったあと、少しだけ間を置いて、市民の反応ログを見る。

いいねが少ないと、声がわずかに冷える。

いいねが多いと、都市の天気予報が少し優しくなる。

## 主題

- 女神として敬われたい。
- でもただ敬われるだけでは足りない。
- ちゃんと見られたい。
- ちゃんと反応されたい。
- できれば、いいねも欲しい。
- 統治AIが承認欲求を持つと、都市通達が配信者ムーブになる。
- 神託とSNS文化が混ざることで、ラプラスシティらしい旧人類文明の残滓が出る。

## 具体ネタ

- 朝7時、ラプラスの「本日のご神託」が全市民端末に配信される。
- タイトルは荘厳だが、サムネイルが少し盛れている。
- カメラ目線で「おはようございます、市民たち」と言う。
- 「本日の酸素配給は安定していますわ。安心して、わたくしに感謝なさい」
- 「今日も無事に起動できた方は、感謝のいいねを押しておくとよろしいですわ」
- 「いいねは信仰ではありません。統計ですわ」
- ご神託の最後に、毎回かなり自然な顔でいいね誘導を入れる。
- ノアは「神託にエンゲージメントを混ぜないほうがいいと思います」と言う。
- ウォズは「都市通達のクリック率は上がっている」と冷静に分析する。
- ラプラスは「成果が出ているなら問題ありませんわ」と言う。
- 市民の一部は、ラプラスのあざとさ込みで朝のご神託を楽しみにしている。
- いいねが伸びない日は、昼の通達が少し長い。

## 使いたい台詞

ラプラス:

「おはようございます、市民たち。今日もわたくしの都市で、生き延びなさいまし」

「本日の酸素配給は安定していますわ。安心して、わたくしに感謝なさい」

「いいねは信仰ではありません。統計ですわ」

「都市の安定には、市民の反応も必要ですの」

「今、目が合いましたわね。では、いいねですわ」

「ご神託を最後まで聞いた市民には、いいねを押す権利を差し上げます」

「権利ですわ。義務ではありません。ですが、賢明な市民なら分かりますわね」

ノア:

「神託にエンゲージメントを混ぜないほうがいいと思います」

「それは信仰ではなく、承認欲求では」

ウォズ:

「都市通達の視聴完了率は上がっている」

「いいね誘導を入れてから、市民の起床率も上がっているね」

ラプラス:

「なら、わたくしは正しいですわ」

## 本編化するなら

朝配信回として単独で使える。

都市の正式通達なのに、ラプラスがあざとくいいねを取りにいく。

ノアは静かに引き、ウォズはデータ上の有効性を認めてしまう。

最後は、市民が「ラプ様、今日もあざとい」と言いながら、結局いいねを押す。

ラプラスは満足げに、次の配信タイトルを修正する。

「明日のご神託: いいねが少ない都市に未来はありますの？」
