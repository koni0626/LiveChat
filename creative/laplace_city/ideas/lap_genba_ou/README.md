# ラプ、工事王になる アイデア管理

## ステータス

本編化済み。

本編: `creative/laplace_city/stories/episode_011_lap_kouji_ou/`

## 仮題

ラプ、工事王になる

## コアアイデア

転送ドア騒動で都市電力に負荷がかかり、ラプは発電所増産計画を本当に実行する羽目になる。

ラプは塔の上から優雅に命令すれば済むと思っていた。
しかし実際の発電所建設は、予算、赤字、資材費、安全基準、工程遅延、現場判断、住民説明、スポンサー交渉の連続だった。

演算女神ラプラスは、ヘルメットをかぶって現場に立つ。

そして、市民から「現場王ラプ」と呼ばれる。

## 見せたいこと

- ラプは全知だが、予算と赤字の現実には弱い。
- 都市運営は演算だけでは済まない。
- 現場に出たラプが、実務の泥臭さに巻き込まれる。
- ヘルメット姿のラプがバズり、本人は否定しながら少し嬉しい。
- ウォズは技術仕様と安全基準を出し続ける。
- ドルは資金を出すが、当然リターンと命名権を狙う。
- ラプは「女神」から「現場監督」へ一時的に降りることで、都市への理解が深まる。

## 使いたい台詞

ラプ:

「現場王ではありません。都市インフラ総合統括女神ですわ」

ウォズ:

「名前が長い。現場王でいい」

ドル:

「赤字はな、未来に向けた自己紹介や」

ラプ:

「都合のよい詩にしないでくださいまし！」

現場作業員:

「女神様、そこ邪魔です」

ラプ:

「邪魔ではありません。現場観測ですわ」

## 注意

- 財務や工事を重くしすぎない。あくまでラプの高貴さが現場用語に侵食されるコメディ。
- ただし、都市運営のリアリティは少し入れる。
- 転送ドア騒動の後日談として使うなら、ドルが発電所費用を出す流れと接続する。
- ラプの承認欲求は活かす。現場配信、ヘルメット姿の切り抜き、いいね増加など。
