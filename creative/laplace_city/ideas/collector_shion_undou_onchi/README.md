## 方向性

コレクタが旧人類の「球技大会」文化を保存するため、ラプラス美術館か救済院の慈善イベントで実演記録を始める。

ただし、コレクタもシオンも運動が壊滅的に下手。

コレクタは身体を動かすたびに展示物のように静止し、シオンは飛んでくるボールを受け止める前に祈る。結果として、スポーツではなく奇妙に荘厳な儀式になる。

さらにマラソンでは、シオンが本人の自覚なしに観客の視線を集めてしまう。

シオンは巨乳キャラなので、走るたびに修道服の胸元が大きく揺れ、男性ヒューマノイドたちの視線ログが一斉に固定される。シオン本人は「みなさん、応援してくださっているのですね」と純粋に受け止めるが、周囲の煩悩は明らかに別方向。

一方コレクタは、なぜかマラソン中に先導バイクの後ろへ乗っている。どうやって乗ったのか誰にも分からない。本人は「先導文化の実演保存です」と言い張る。

球技では、お約束のようにボールがシオンの大きな胸に収まる。キャッチボールでも、野球でも、ビーチバレーでも、どんな球技でも最終的にそこへ収まる。シオン本人は「受け止められました」と喜ぶが、周囲は反応に困る。

## 使いたい要素

- 「運動音痴な二人」
- 「シオンのキャッチ」
- どんな球技でも、最終的にボールがシオンの胸に収まるお約束。
- 「今度は野球」
- 「当たるわけがない」
- 「天罰」
- 「ただの変な動き」
- 「シオン大人気」
- マラソンでシオンの胸元が揺れ、男性ヒューマノイドの視線が釘付けになる。
- コレクタがなぜか先導バイクの後ろに乗っている。
- 「今度はビーチバレー」
- 「でしょうね。」
- 「はい、お約束」

## キャラの見せ方

- コレクタは失敗を失敗として恥じない。「未保存の身体文化です」と言い張る。
- シオンは天然で、ボールにも相手にも謝る。
- シオンは本人の自覚がないまま人気が出る。
- シオンの人気は、清らかさと無自覚な色気のギャップで発生する。本人は応援だと思っている。
- シオンは胸でボールを受け止めても、ただ「キャッチできました」と思っている。
- コレクタは人気そのものより、失敗動作の保存価値を見ている。
- コレクタはずるがしこく、競技に参加している顔でいつの間にか楽をしている。
