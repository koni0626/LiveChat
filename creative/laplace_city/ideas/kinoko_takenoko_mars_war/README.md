# 旧人類、菓子で戦争す

## ステータス

本編化済み。

本編: `creative/laplace_city/stories/episode_016_kinoko_takenoko_war/`

## 位置づけ

第16話。

旧人類が「きのこの山か、たけのこの里か」という菓子論争を、火星移住後まで持ち込んだ話。

限られた火星資源では、両方を同時に安定生産することが難しかったため、単なる好みの違いが資源配分、政治、信仰、居住区対立に発展する。

## コアアイデア

旧人類は、火星まで来てなお、菓子の派閥で揉めていた。

酸素も水も足りない。

カカオも砂糖も包装材も足りない。

製造ラインも一本しかない。

それでも人類は、どちらを作るかで揉めた。

## 注意

- 実在商品名を使うため、商品そのものを悪く言わない。
- 笑う対象は、旧人類の派閥化、聖地化、資源配分の政治化。
- 最終的には、両方とも美味しかったから争いが続いた、という方向にする。
