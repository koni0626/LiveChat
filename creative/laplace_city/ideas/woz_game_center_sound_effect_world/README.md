ウォズのゲームセンター、全部プッになる

または

ウォズのゲームセンター、効果音の世界になる

## 位置づけ

ウォズのゲームセンターで、動作に付く効果音が現実へ漏れ出す話。

当初は、ポンがジャンプしたら「ピョン」、コインを取ったら「チャリン」、ノアが歩いたら「ぽく、ぽく」のように、キャラや動作に合った効果音が鳴る想定だった。

しかし、実際にはすべての効果音が、なぜか「プッ」に統一されてしまう。

しかも鳴るタイミングが最悪。

特定のアトラクションに閉じない。

ウォズのゲームセンター全域で、何かを確定した瞬間、かがんだ瞬間、優雅に脚を組んだ瞬間、名乗った瞬間、クリックした瞬間に鳴る。

ウォズが自販機でコーヒーを買い、取り出し口へかがんだ瞬間。

「プッ」

ドルがメダル貸出機のカップを取ろうとして前屈みになった瞬間。

「プッ」

ダンスゲームをクリアして決めポーズを取った瞬間。

「プッ」

エアホッケーでラプラスが勝ち、うれしくて勝利ポーズを取った瞬間。

「プッ」

ドルが負けて「くそー」と筐体に手をついた瞬間。

「プッ」

UFOキャッチャー風のクレーンゲームで、ノアがぬいぐるみを取り出そうと前屈みになった瞬間。

「プッ」

ラプラスが「わたくし、ラプ」と言った瞬間。

「プッ」

「ここで鳴ったら終わり」という場面でだけ、ゲームセンターの音響システムが律儀に「プッ」と鳴らす。

## コアアイデア

旧人類ゲーム文化の「効果音」が、ラプラスシティの現実認識に混ざってしまう。

ウォズが旧人類ゲームセンターに、動作へ自動で効果音を付ける体験型音響システムを導入する。

本来は、ジャンプなら「ピョン」、走るなら「タタタ」、転ぶなら「ズベッ」、アイテム取得なら「チャリン」という具合に、ゲームっぽい音を重ねるだけのはずだった。

ところが、音響AIが旧人類のドッキリ番組、下品な効果音文化、気まずい沈黙を破壊する笑いを誤学習する。

その結果、本人の動作とまったく関係なく、全員に「プッ」が鳴る。

誰が鳴らしたのか分からない。

だから全員が疑われる。

さらに終盤で、人狼ゲームのような疑念が生まれる。

「この中に一人、本当に鳴らした者がいる」

筐体SEだけだと思っていた全員が、急に互いを観測し始める。

オチはノア。

システム停止後、最後に本当に小さく鳴る。

ここではすぐ白状させず、ドルがウォズ、ラプラス、ノアを順に疑う。

ノアは最後まで静かに否定気味に振る舞うが、ウォズの環境マイク記録と、トイレ後から少し無口だったことを突っ込まれて観念する。

最後にノアが静かに手を上げる。

「今のは、わたしです」

オチ後は、ノアも普通に弄られる。

ドルが「今日だけ、いただきました」と言い、ノアが「記録しないで」と返す。

ウォズのゲームセンター。

- 最後に「プッは、みんなを止める音？」と聞く。

## 面白さの軸

- こいてはいけないシリアスな場面ほど、筐体が「プッ」と鳴らす。
- ゲームセンター内の日常動作すべてが危険になる。
- かがむ、クリックする、脚を組む、名乗るなど、本人に罪がない動作ほど疑われる。
- ごまかすための音まで「プッ」になり、むしろ増幅される。
- 誰が鳴らしたか分からず、密室推理みたいになる。
- 実際には全部筐体SEなのに、全員の信用が少しずつ減る。
- と思わせて、最後だけ本当に誰かが鳴らしていたことが判明し、人狼ゲームになる。
- オチはノア。白状はすぐにさせず、ウォズ、ドル、ラプラス、ノアに順番に疑いが向く。
- ノアは弄られキャラに戻し、オチ後は「今日だけ」をドルに拾われる。
- ラプラスの神格、ノアの静けさ、ウォズの理性、ドルの品のなさが同時に揺れる。
- ポンだけが純粋に「何の音？」と聞き、周囲が詰む。
