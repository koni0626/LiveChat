# ラプとノア、星を見に行く

## ステータス

保管中。

## 方向性

ラプとノアの静かな関係回。

ノアがラプに手を差し伸べる話として使える。大きな事件で助けるのではなく、ラプを都市運営と全知の役割から少しだけ外へ連れ出す。

ラプにとってノアは「未来が分かっていても、一緒に行かなければ分からないもの」を思い出させる相手。

## 元ネタ

### 1枚目

ラプラス自然公園。

ラプラスシティの郊外。

未開の火星の大地。

ラプラスが、

「もう、都市開発めんどくさいですの」

と言い出して、開発終了。

以降、3000年間ほったらかし。

この道の先にハタラケ姫の会社があることはあまり知られていない。

### 2枚目

ラプラスが星を見ながら言う。

「未来は大体わかってしまいますけど」

ノアが少し笑う。

「それでも来てみないと分からないよ」

ラプラスが小さく笑う。

「だからノアと旅してる」

## 主題

- ラプは全知だが、体験を代替できるわけではない。
- ノアは未来を確定させず、実際に来て、見て、揺れる余白を大切にする。
- ラプは都市開発に疲れると「めんどくさいですの」で投げる。
- その投げた場所が、結果として自然公園になる。
- 全知と未確定が、ドライブという小さな旅で並ぶ。

## 本編化メモ

ラプが疲れている回の後に入れるとよい。

「ラプ、計算をやめる夜」系の話と相性がいい。

また、ハタラケ姫の会社への導線にもできる。

ラプラス自然公園の先にハタラケ姫の会社がある、という妙な不穏さを最後に軽く置ける。
