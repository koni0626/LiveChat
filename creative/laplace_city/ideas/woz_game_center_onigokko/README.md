# ウォズのゲームセンターで鬼ごっこ

## ステータス

保管中。

第21話以降の候補。

## 仮題

ウォズのゲームセンターで鬼ごっこ

または

ラプラスシティ逃走中

## 位置づけ

旧人類の逃走系バラエティ番組を、ウォズがゲームセンター用の体験型アトラクションとして復元する話。

参加者は制限時間内、ゲームセンター内の複数フロア、筐体迷路、旧人類アーケード街、ホログラム路地を逃げ回る。

黒服・サングラス風の無表情な追跡AI「ハンター」に見つかると追跡され、捕まると失格。

## コアアイデア

旧人類は、追われる恐怖まで娯楽にした。

ラプラスシティのヒューマノイドたちは、最初は「なぜわざわざ怖い思いをするのか」と首をかしげる。

しかし、制限時間、賞金、承認指数、ミッション、裏切り、隠れるか走るかの判断が入った瞬間、全員の人間由来の学習データが反応してしまう。

## 舞台

ウォズのゲームセンター。

DB上の `旧人類ゲームセンター` を、ウォズが復元・改造・運用している体験型施設として扱う。

施設内には、旧人類風のアーケード筐体、クレーンゲーム、レースゲーム、音ゲー、ネオン看板、ホログラム迷路、メンテナンス通路がある。

ウォズは「安全な検証用アトラクション」と言い張るが、ハンターの挙動が本気すぎる。

## 流行している効果音

なぜかラプラスシティでは、走り出す時の効果音として「シュタタタタツ！」が流行している。

元ネタは不明。

旧人類の漫画効果音、忍者走り、逃走系番組の編集音、ゲームセンターの筐体SEが混ざって都市ネットワーク上でミーム化したもの。

誰かが走り出すと、市民が口で「シュタタタタツ！」と言う。

追跡AIの足音ログにも、なぜか自動字幕で「シュタタタタツ！」が出る。

ラプラスが実況で言うと承認指数が上がるため、本人も少し気に入っている。

## 使いたいキャラ

- ウォズ: 企画・設計者。安全な遊びのつもりで作ったが、ハンターAIの最適化が強すぎる。
- ラプラス: 実況・承認指数管理。逃走確率を見てしまうので、ついネタバレしかける。
- ノア: 「争いはよくない」と言いながら、隠密・逃走・気配消しが異様にうまい。
- ドル: 賞金、スポンサー、逃走成功オッズに反応する。自首システムにも興味を持つ。
- ポン: 「逃げるって、仕事？」と悩む。最初は真面目にルール確認するが、走る時に「シュタタタタツ！」を覚える。
- ハタラケ姫: 「逃げる体力があるなら働け」と言い、なぜかハンター側に回りたがる。
- コレクタ: 捕まった参加者の名言と絶望顔を展示しようとする。
- マリン: 疑似ポイントで逃走成功予想を煽る。

## 面白さの軸

- 旧人類の「追われる恐怖を娯楽にする」文化を、ラプラスシティが真面目に復元してしまう。
- ウォズの安全設計が本気すぎて、ハンターが普通に怖い。
- ラプラスが実況で「逃走成功率、三パーセントですわ」と言ってしまい、参加者の心を折る。
- ノアは静かに隠れるだけでハンターをやり過ごす。周囲が「ノア、またそういうのできるの？」となる。
- ポンは逃げることを「怒られないため」ではなく「遊びとして選ぶ」練習にできる。
- 「シュタタタタツ！」が無意味に流行し、緊迫シーンを全部少しアホにする。

## 使いたい展開

1. ウォズが旧人類ゲームセンターに新アトラクションを作る。
2. 旧人類の逃走系バラエティ番組を復元したと言う。
3. ラプラス、ノア、ドル、ポンたちがテストプレイに参加。
4. 黒服ハンターが出現し、思ったより怖い。
5. 最初の逃走者が走り出した瞬間、観客席から「シュタタタタツ！」が流行語のように飛ぶ。
6. ラプラスが実況し、逃走確率を言ってしまう。
7. ドルが賞金と自首システムに目をつける。
8. ポンが「逃げるって、仕事じゃないの？」とノアに聞く。
9. ノアが「これは、遊びとして逃げていい時間」と答える。
10. ハタラケ姫がハンター側に現れ、空気が変わる。
11. ノアが静かに気配を消し、ハンターの真横を通り抜ける。
12. ラストはポンが初めて楽しそうに「シュタタタタツ！」と言って走る。
