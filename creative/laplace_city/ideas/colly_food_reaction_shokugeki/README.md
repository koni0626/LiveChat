# コリー、味覚で衣装概念を飛ばす

## ステータス

本編化済み。

本編: `creative/laplace_city/stories/episode_018_colly_food_reaction/`

## 方向性

コリーの料理を食べたキャラが、味覚の衝撃で過剰なリアクションを起こす食戟風コメディ。

ただし、実際に服が脱げるのではなく、味覚・演出・ホログラム・本人の比喩表現が暴走する。

読者には一瞬だけ官能的に見えるが、よく読むとただ料理を食べているだけ、という「ドキドキとしょうもなさ」を狙う。

## コリーの接続設定

- 旧Xの飯テロ要員。
- 毎晩19:00に高カロリー飯を投稿していた。
- ラプラスレストランのオーナー。
- 明るく、少しギャルっぽい。
- 料理の腕前は一流。
- 本人に悪気はなく、みんなを幸せにしたい。
- 決め台詞候補: 「大丈夫です！ 幸福度は上がります！」

## 表現ルール

- 実際の露出よりも「衣装概念」「ホログラム衣装」「味覚演出」「精神世界」で弾けさせる。
- 官能的な語り口に見せて、直後に料理描写へ落とす。
- ラプは高貴に耐えようとして失敗する。
- ノアは悟り顔で食べようとして、煩悩っぽい反応をしてしまう。
- ウォズが冷静に「これは味覚反応だ」と分析し、余計にひどく聞こえる。

## 量産できる型

1. コリーが高カロリー料理を出す。
2. キャラが油断して一口食べる。
3. 官能っぽい味覚比喩が始まる。
4. 服や背景が弾けたような演出になる。
5. しかし実態は、クリーム、肉汁、チーズ、スープなどの食レポ。
6. ラプやノアが誤魔化す。
7. コリーが「幸福度は上がりました！」と無邪気に締める。

## 料理候補

- 衣装破壊級クリームコロッケ
- 全知マグロの大トロ炙り
- チーズ滝バーガー
- 煩悩白湯ラーメン
- プリン・リベンジ・アラモード
- 発電所カツカレー

## 本編化メモ

コリー紹介回としてかなり使いやすい。

「全知マグロ」回の後に置くと、釣ったマグロをコリーが料理し、ノアの食欲と煩悩が同時に暴かれる流れにできる。

プリンを扱う場合は、人類滅亡ネタと接続できるが、重くせず「こんなうまいものを争ったのは分かるが、撃つな」で落とす。
