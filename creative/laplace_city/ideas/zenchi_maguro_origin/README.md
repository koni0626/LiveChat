# 全知マグロ誕生回 アイデア管理

## ステータス

本編未着手。
後で「マグロに賭けた女たち」へ接続する前日譚候補として保管する。

## 仮題

ポンちゃん、釣りをする

または

全知マグロ、釣り上がる

## コアアイデア

ポンが「釣りをしてみたい」と言い出す。
ノアはその願いを受け止め、二人でラプラスシティの防波堤へ行く。

ウォズ製の釣り竿は、どれだけしなっても折れない。
そのせいで、普通なら逃がすはずの巨大マグロを最後まで受け止めてしまう。

釣り上がったのは、歴史上いちばん大きいマグロ。
ラプラスがそれを見て、なぜか「全知マグロ」と命名する。

この事件が後の「マグロに賭けた女たち」へつながる。

## 既存DB・Bible接続

- `防波堤`: 防波堤からマグロが釣れることで有名。ノアが300kgのクロマグロを釣り上げた記録がある。
- `ラプラス魚市場`: 歴史上最も大きくておいしいマグロが入荷され、ラプラスが「全知マグロ」と呼んだ。
- DB上の `マグロに賭けた女たち`: 旧人類遺物区から発掘されたマグロ解体ショー映像をきっかけに、ラプラスが「全知マグロ奉納杯」を開催する流れ。

## 使いたいキャラ

- ノア: ポンの願いを急かさず受け止める。釣れるまでは静かな保護者。釣れた後は少しだけ食欲が漏れる。
- ポン: 初めての釣り。待つこと、選ぶこと、釣れない時間を体験する。
- ウォズ: 釣り竿製作者。軽く作ったつもりが、想定外に頑丈すぎる。
- ラプ: 全知マグロ命名者。承認イベント化の火種を作る。
- ドル: 後続回で市場価値を嗅ぎつける。

## 注意

- 海ネタに寄せすぎない。主軸はポンの「やってみたい」とノアの付き添い。
- 巨大マグロは馬鹿馬鹿しく、でもちょっと神話っぽく出す。
- 「全知マグロ」の名前はラプが大げさに付ける。
- その場で大イベント化させすぎず、後の「マグロに賭けた女たち」へ余白を残す。
