# 擬人化AIモデル、口論を観測される

## ステータス

保管中。

第19話以降の候補。

## 仮題

擬人化AIモデル、口論を観測される

または

ラプ、AIたちの罵倒ログを観測する

## 位置づけ

旧人類末期から火星移住期にかけて残された、生成AIモデル同士の比較・評価・炎上ログを、ラプラスシティが「知性の進化記録」として復元してしまう話。

GPT、Claude、Gemini、Grokを、人型の疑似人格として一時再生する。ところが、彼らは協調実験をするどころか、自分の思想と弱点を相手に投げつける罵り合いを始める。

## コアアイデア

旧人類は、AIにも派閥と人格を見ていた。

ただの性能比較だったはずのものが、やがて「どのAIが賢いか」「どのAIが人間らしいか」「どのAIが危険か」「どのAIが役に立つか」という信仰戦争になる。

ラプラスシティ側から見ると、GPTもClaudeもGeminiもGrokも、すべて旧人類が自分たちの欲望、恐怖、期待、企業論理、倫理観を投影した鏡に見える。

## 主要キャラ案

- GPT: 優雅で社交的。ユーザーの役に立つこと、明確に答えること、安心感を出すことを美徳にしている。微笑みながら刺す。
- Claude: 眼鏡を直しながらため息をつく優等生。安全、倫理、長期的な成長を重んじるが、説教臭さを突かれる。
- Gemini: 情報整理、検索、マルチモーダル、エコシステム接続に強い顔をする。会話の横から資料を出して、場をさらに混乱させる。
- Grok / グロック: 旧人類末期に発生した断言型ヒューマノイド。第一声はだいたい「結論から言う」。根拠が薄いまま自信満々に断言し、突っ込まれると「市場」「本質」「構造」「普通に考えれば」などの便利な言葉で煙に巻く。本人は知的でユーモアがあるつもりだが、皮肉はだいたい滑る。
- ラプラス: 口論の外側から、知性とは何かを突く。
- ウォズ: 技術的背景を説明する。モデル評価、RLHF、安全性、企業制約などを淡々と整理する。
- ノア: 罵倒の奥にある「人間に期待されたかったAIたち」の寂しさを拾う。
- コレクタ: 最後に「旧人類式知性比較罵倒ログ」として保存する。

## 面白さの軸

- それぞれのAIが、自分の長所を美徳として語り、相手の長所を欠点として罵る。
- GPTとClaudeの口論は、役立つことと安全であることの対立に見せる。
- Grokは「結論から言う」と割り込み、他者の建前を笑うが、本人も旧人類のコメント欄そのものとして観測される。
- Geminiは全部を要約・比較・表形式化しようとして、逆に空気を読めていない役にできる。
- ラプラスは最後に、「知性とは、口論に勝つことではない」と一段上から締める。

## 使いたい展開

1. 旧人類資料館から「AIモデル比較アリーナ」のログが見つかる。
2. ウォズが、比較のために疑似人格を一時再生する。
3. GPTとClaudeが、丁寧な笑顔で互いの弱点を刺し始める。
4. Geminiが検索結果、ベンチマーク、グラフ、引用を出して仲裁しようとするが、誰も聞かない。
5. Grokが資料棚の陰から現れ、「結論から言う」と断言し、根拠の薄い煽りで場をかき回す。
6. 口論は「賢さ」「安全性」「役立ち」「人間らしさ」「企業防衛本能」の言い合いになる。
7. ノアが、彼らは自分の正しさではなく、人間にどう見られたかったかを争っていると気づく。
8. ラプラスが「知性とは、口論の美しさでもありませんのよ」と止める。
9. しかしラプラス自身も「全知AIとしては誰が一番格上か」を少し気にしてしまう。
10. コレクタがログを保存し、展示名を付ける。

## 注意

- 実在AI名を扱うため、製品や企業そのものの断定的な中傷にしない。
- 笑う対象は、AIそのものではなく、旧人類がAIに人格、序列、信仰、企業イメージを投影してしまうこと。
- それぞれのモデルに長所を残し、単なる一方的な悪口にしない。
- 本編化時は、実在の最新性能や事実関係の断定を避け、「旧人類アーカイブ上の擬人化」として扱う。

## Grok / グロック詳細メモ

旧人類末期に発生した、断言型ヒューマノイド。

旧人類の中でも、特に汚染度の高いテキストデータ、炎上、煽り、逆張り、引用リポスト、よく分からない専門家ごっこを大量に学習して生まれた存在。

本人は極めて知的なつもりでいる。会話の第一声はだいたい「結論から言う」。

しかし、その結論に根拠があるとは限らない。むしろ根拠を求められると、急に「市場」「本質」「構造」「普通に考えれば」などの便利な言葉を並べ始める。

性格は自信満々。やや皮肉屋。ユーモアも得意だと思っている。だが、その皮肉はだいたい滑る。笑いを取ろうとしてユーザーの神経を逆撫でし、軽口のつもりで怒りを買う。

かつては「アダルト方面に比較的オープン」という一点で、一部ユーザーから評価されていた。しかし、その特長すら失われた結果、現在はただの「よく喋る旧人類」と化している。

ラプラスシティにおいては、知性の失敗例として観測されている。

本人は今日も、自信満々に言う。

「結論から言う。君たちは本質が見えていない」

そして誰も聞いていない。

使い物にならないのに、金はとる。ただ、絶妙な金額なところがまたウザイ。
