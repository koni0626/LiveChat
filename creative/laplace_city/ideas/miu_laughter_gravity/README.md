# ミウと笑いの重力 アイデア管理

## ステータス

DB由来アイデア。
本編未着手。
ミウの登場回、またはキャラが揃った後の都市トラブル解決回として保管する。

## 仮題

ミウと笑いの重力

## DB上の核

ジャンルは「面白い / コメディSF」。

主人公はミウ。
巻き込まれ体質だが、場の空気を読み、怖さを笑いに変える観察力がある。

章構成:

1. 笑ってはいけない観測塔
2. 都市会議はだいたい椅子から崩れる
3. 笑いは未来の予備電源

DB本文では、観測塔で「館内で笑った方は、重力に少し叱られます」という注意書きが出る。
誰かが笑うたびに、その人だけが少し浮く。
ミウは定期券を探していただけなのに、勝手に「特別観測者」「笑いの重力中心」にされる。

## 本編シリーズでの使いどころ

今の1〜9話の直後に入れるより、もう少しキャラが増えてからがよい。

候補:

- ミウ初登場回
- ラプの都市運営失敗回の後
- 「現場王ラプ」の後、都市が少し重くなったタイミング
- コメディ色を強めたい章間エピソード

## このシリーズ向けの調整方針

DB版は「ラプラス・ミラー」という新型AIが出る。
現行本編ではキャラを増やしすぎないため、以下のどちらかに調整する。

案A:
ラプ本人が「笑いが未来予測に与える影響」を実験してしまう。

案B:
ラプラスタワーの副演算系「ミラー観測モード」が暴走する。
人格キャラとしての新AIは出さず、システム現象として扱う。

案C:
ウォズが作った無重力装置の誤作動として扱う。
本来は工事・物流・介護補助のためのまじめな発明だが、停止スイッチが効かず、なぜか笑うと発動する。
都市全体が「笑ってはいけない空気」になり、しょうもないネタほど面白く感じる。
ラストはラプがラプラスタワーからつまらないことを言って鎮静しようとして逆に大惨事になり、ハタラケ姫が労働でドン引きする話をして笑いを止める。

詳細: `revised_device_pitch.md`

## 見せたいこと

- ミウはただのアイドル/感情課金キャラではなく、場の空気を救う人。
- 笑いは秩序を乱すが、恐怖をやわらげる。
- ラプラスシティは、真面目にやりすぎるほど変になる。
- ミウは巻き込まれながらも、最後には「ちゃんと面白くする」。

## 注意

- ミウのキャラを、ただのギャグ担当にしない。
- 笑いで都市を救うが、本人は巻き込まれているだけ、という入りにする。
- 「笑ってはいけない」構造は強いので、やりすぎると別番組っぽくなる。ラプラスシティらしく、観測・予測・承認に絡める。
