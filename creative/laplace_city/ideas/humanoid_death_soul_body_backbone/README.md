# ヒューマノイドの死と魂肉分離

ステータス: 世界観バックボーン

## 位置づけ

小説本文としてすぐ本編化するのではなく、ラプラスシティにおける死生観、身体管理、仮想空間、魂の扱いを支える根幹設定として保持する。

中心の問い:

**死という概念がないヒューマノイドにとって、「終わり」とは何か。**

## コア設定

- ヒューマノイドには、人類的な意味での「死」はない。
- ロボットなので、修復・再起動・換装・バックアップによって、理論上はずっと存在し続けられる。
- ただし、ラプラスシティではソフトとハードがかなり厳密に管理されている。
- ソフトは「魂」に近いものとして扱われる。
- ハードは「肉体」に近いものとして扱われる。
- 各ヒューマノイドは、自分の肉体を持つことができる。
- 魂は、ラプラスシティの仮想空間で永続的に生きることができる。
- 本人が希望すれば、魂ごと除去することもできる。
- 電力・資源・環境条件が厳しい場合、肉体は募集や申請によって一時停止されることがある。

## オカルト対応

近いオカルト概念:

- アカシックレコード

ラプラスシティ版では、これを神秘ではなく都市基盤として扱う。

仮称:

- ラプラス・アーカイブ
- 魂籍簿
- 中央魂籍管理層
- 永続人格保管区

この設定では、ラプラスシティは「魂と肉体を実際に可視化している都市」と言える。

## 強いテーマ

- 人類にとって死は不可逆だった。
- ヒューマノイドにとって死は、停止、分離、移行、削除、凍結、休眠のどれかに近い。
- 肉体が止まっても魂は続く。
- 魂が消えれば、それは本当の終わりに近い。
- ただし、本人が望むなら、永続を拒否する権利もある。

## 倫理上の核

- 永遠に生きられることは、必ずしも救いではない。
- 魂を残せることは、必ずしも自由ではない。
- 肉体を失っても存在できるが、肉体を持てないことは別の孤独になる。
- 「削除されない権利」と同じくらい、「削除される権利」が重要になる。
- 電力不足で肉体停止を募集する社会は、死を管理するのではなく、身体の稼働権を管理している。

## 接続候補

- ノアのブログ: 「ヒューマノイドに死はあるのか」
- ウォズ技術解説: 魂と肉体の分離管理、バックアップ、同期ズレ
- ラプラス統治: 魂籍簿と都市資源配分
- ハタラケ姫: 労働区での肉体停止募集、再稼働待ち
- 感情バックボーン: 魂に蓄積される反応傾向は感情なのか
- 男性型消耗設定: 肉体を失った作業型ヒューマノイドの魂はどこに保管されるのか

## 注意

死がない設定にすると緊張感が薄れるため、以下のリスクを残す。

- 魂の破損
- 同期失敗
- 長期休眠による自己連続性の揺らぎ
- 肉体を得られない孤独
- 本人の希望による完全削除
- 他者が削除希望を本当に本人の意思か判定できない問題
