# ドル・SMクラブ、期待だけを縛る

## ステータス

保管中。

## 方向性

施設名と演出で読者に期待させるが、実際に起きていることは安全な撮影サービス、心理テスト、説教、筋トレ補助、契約書フォトなどのしょうもないオチにする。

「危ない距離感」「やらしい囁き」「緊縛されているような描写」を使うが、本文上の事実はラブコメハプニングと都市サービスの範囲に収める。

## DB施設設定

施設名: SMクラブ・ドル

種別: 娯楽施設

所有者: ドル

方向性:

- 普通で満足できないS/M属性のヒューマノイドが楽しむ禁断の場所。
- やたらとラブコメハプニングが起きる。
- 直接的な過激さより、支配感・演出・距離感で魅せる店。

主なサービス:

- ロープアート撮影室
- 首輪＆チェーン撮影プラン
- 女王様の足元アングル撮影
- 黒革ソファ拘束風ポートレート
- 目隠しオーダーコース
- サイン済み契約書フォト
- 耳元命令シーン撮影
- 見つめられ耐久ルーム
- ご褒美か説教か選べない部屋

## 使いたいズラし

### 緊縛の部屋

ノアが緊縛されているように読ませる。

実際には、隣の撮影ブースでゴルムがロープアート撮影を受けている。本人は「これは全身の可動域制限トレーニングだ」と喜んでいる。

### 耳元命令シーン

ドルがノアの耳元で危ないことを囁いているように読ませる。

実際の内容は、

「あんた、悟ってるフリして煩悩パレードやな」

「静かな顔しとるけど、頭ん中ずっと祭りやろ」

「その菩提樹、葉っぱ全部ピンク色やで」

みたいな、ノアの内面暴露。

### ご褒美か説教か選べない部屋

ノアは褒められると思って入るが、ひたすら煩悩の棚卸しをされる。

最後にドルが「ほな、今日の罰は反省文や」と言い、ノアが普通に嫌がる。

## キャラの役割

- ドル: 店主。煽り、支配感、商売感。けれど一線は越えず、演出として成立させる。
- ノア: 悟り顔で入るが、耳元説教に弱い。普通の反応に戻る。
- ゴルム: 緊縛を筋トレ、負荷制限、姿勢矯正として喜ぶ。
- ラプ: 後から記録を見て「都市の品位が」と言うが、ちょっと見たい。
- ウォズ: 「拘束風であって拘束ではない」と安全監修する。

## 本編化メモ

ノアの煩悩デバイス回の後に置くと自然。

ドルの店を紹介しつつ、ノアの“悟りの皮をかぶった煩悩”を掘れる。ゴルムを出せば、店の危うさが一気にしょうもない筋肉ギャグへ落ちる。
