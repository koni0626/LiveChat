# ラプラスシティ アイデア管理

本編化前のネタ、後日談候補、別回に温存したい素材を置く場所。

## 運用ルール

- まだ本編番号を振らない。
- 1アイデアにつき1フォルダ。
- 各フォルダには、最低限 `README.md` と `draft.md` を置く。
- DBや既存話との接続がある場合は `db_connection_notes.md` または `continuity_notes.md` を置く。
- 本編化するときは `stories/episode_XXX_*` に移し、この一覧のステータスを更新する。
