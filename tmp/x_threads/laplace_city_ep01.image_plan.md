# ラプラスシティ第1話 X用画像案

目的: 全ポストに挿絵を付けるのではなく、Xで手を止める「事件の一瞬」だけを画像化する。

方針:

- 画像は最大3枚。まずは1枚目だけ生成判断する。
- 未来都市の説明絵にしない。
- ラプラスの立ち絵にしない。
- 「プリン」「戦争」「呆れるラプ」「人類のしょうもなさ」が同じ画面で分かること。
- 既存ショート漫画方式に合わせ、caption / tone / emotion / shot / visual_focus / image_prompt で作る。
- 生成前にこの案を人間が見て、弱いものは捨てる。

## 採用候補 1: 開幕サムネ

caption: プリンを奪う者に、未来を語る資格はない

tone: black comedy / apocalyptic satire

emotion: ラプラスは激怒ではなく、心底あきれている。人類に対する静かな失望と軽蔑。

shot: 16:9 horizontal thumbnail, dramatic close-up + incident scene

visual_focus: ガラスケースのプリンを原因に、火星都市でミサイルが発射されている。右に呆れ顔のラプラス、左に巨大な見出し。

image_prompt:

```text
添付のラプラス基準画像を、キャラクターの顔・髪型・瞳・衣装・青い発光装飾・画風の最優先基準として使う。

16:9 横長のX投稿用サムネイル。高インパクトなショート漫画サムネ調。ただしキャラクターの絵柄と質感は基準画像に寄せる。

これは「人類がプリンで滅びた」事件の一瞬。
画面手前に、ガラスケースに入った高級プリンを大きく配置する。プリンはこの画像の事件原因として一目で分かるようにする。
背景は赤い火星の空、未来都市、複数のミサイル発射の軌跡、遠景の爆発。
右側にラプラスの大きなバストアップ。怒鳴る顔ではなく、半目で見下ろすような冷たい呆れ顔。口元だけわずかに冷笑。「人類、またですの……？」という表情。

左側に大きく読みやすい日本語見出しを入れる。

画像内テキストは以下だけ。他の文字、看板、ロゴ、UI、読めない記号、英語は禁止。

メイン見出し:
プリンを奪う者に、
未来を語る資格はない

サブ見出し:
人類は、プリンで滅びました

文字は白太字、黒と赤の太い縁取り。スマホで小さく表示されても読める。人物、プリン、ミサイル、見出しがすべて画面内に収まる。
```

採用理由:

- 第1ポストのフックそのもの。
- 画像単体で「何だこれ」となる。
- ラプラスのキャラ性も出る。

リスク:

- 文字精度に失敗したら使えない。
- ただし1枚目は文字が武器なので、ここだけは文字入りで勝負する価値がある。

## 採用候補 2: 和平晩餐会の崩壊

caption: 人類は、プリンで滅びました

tone: black comedy / disaster comedy

emotion: 会場全体が凍りつく。しょうもない原因なのに世界が終わる。

shot: 16:9 horizontal event CG, low angle from table level

visual_focus: 豪華な和平晩餐会で、最後のプリンをめぐって代表者たちが硬直し、窓の外でミサイルが上がる。

image_prompt:

```text
16:9 横長のX投稿用イベントCG。高品質なSFブラックコメディ。

これは「最後の和平晩餐会で、限定プリンが一つ足りなかった」瞬間。
カメラは豪華な長テーブルの低い位置。画面手前に空のプリン皿と、最後の一つのプリンを守る小さなガラスケース。
左右には対立する代表者たちが座り、全員がプリンを見て凍りついている。怒鳴る直前、誰もまだ動けない一秒。
大きな窓の外には赤い火星都市。遠くでミサイルが発射され、空に白い軌跡が伸びている。

事件の原因がプリンだと一目で分かるようにする。プリン、代表者たちの硬直、窓外のミサイルを必ず見せる。
ただの未来都市、ただの会議室、ただの食事風景にしない。

画像内テキストは入れない。看板、ロゴ、UI、読めない記号、英語も入れない。
```

採用理由:

- 第6ポストに対応。
- 文字なしでも「何かバカな理由で戦争が起きた」絵にできる可能性がある。
- 1枚目の補強として使える。

リスク:

- 生成がただの会議室になると弱い。
- プリンを大きく置けないと失敗。

## 採用候補 3: 鎮圧ですわ

caption: 鎮圧ですわ

tone: comedy / divine intervention

emotion: ラプラスは静かに呆れている。ウォズは「本当にやるの？」という顔。

shot: 16:9 horizontal social-video incident still, over-the-shoulder / walking shot

visual_focus: 限定プリン売り場でヒューマノイドたちが整理券地獄を起こし、ラプラスが神罰寸前の静けさで現場へ向かう。

image_prompt:

```text
添付のラプラス基準画像をラプラスの基準にする。添付のウォズ基準画像がある場合はウォズの基準にする。

16:9 横長のX投稿用イベントCG。ラプラスシティのネオン街、中央生活区のスイーツ店前。

画面奥では、透明ケースの限定プリンをめぐってヒューマノイドたちが整理券の整理券で混乱している。
列が絡まり、整理券を持つ人々、困惑する小型ロボット、プリンを守るガラスケースが見える。
画面手前または右側に、ラプラスが静かに歩いてくる。怒ってはいない。半目で、心底あきれた顔。青い光が少し強くなり、神罰の気配だけがある。
近くにウォズがいる場合、ウォズは「予測？」と聞きたそうな困惑顔。

これはポスターではなく、騒動現場にラプラスが到着した瞬間。人物は立ち絵にしない。プリン、列、整理券地獄、ラプラスの呆れ顔が同時に分かる構図。

画像内テキストを入れる場合は次の一語だけ:
鎮圧ですわ

他の文字、看板、ロゴ、UI、読めない記号、英語は禁止。
```

採用理由:

- 第9ポストのオチ直前に合う。
- ラプラスシティ本編の空気が最も出る。
- 「神々しいのに原因がプリン」の構造が作れる。

リスク:

- 背景がごちゃつくと弱い。
- 文字入りにするなら短いので比較的通りやすいが、失敗時は文字なし版にする。

## 捨てる方針

以下は生成しない:

- 火星都市の風景だけ
- ラプラス単独の綺麗な立ち絵
- 初代CEOの銅像や企業広告だけ
- ラプラス誕生の神秘的な絵だけ
- ただの群衆、ただの会議、ただの未来都市

理由:

本文の説明にはなるが、Xで手を止める異物感が弱い。

## 推奨順

1. 候補1だけをまず低コストで試す。
2. 文字が成功し、ラプの表情が合えば採用。
3. 候補1が強ければ、候補2か3を追加検討。
4. 候補1が弱い場合、追加生成せずプロンプトを作り直す。
